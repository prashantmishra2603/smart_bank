# SmartBank

Secure Banking. Simple Transactions.

This is a portfolio-level full-stack banking application built with Spring Boot and React.

## Tech Stack
- Backend: Java 21, Spring Boot 3.x, Spring Security, JWT, PostgreSQL, Flyway, Maven
- Frontend: React 19, Vite (To be implemented)

## Local Setup
1. Run `docker compose up -d` to start the PostgreSQL database.
2. Navigate to `backend` directory and run `./mvnw spring-boot:run` to start the backend server.
